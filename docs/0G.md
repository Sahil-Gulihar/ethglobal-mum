# 0G track: Verified buyers

**One sentence:** without 0G, the checkout has no defence against bots: no fresh picture to draw, no spoken answer to transcribe, and no answer to judge, and bot attempts cost nothing, because the buyer's own 0G credits pay for each try.

## Try it (about 2 minutes)

1. Open the demo store at https://demo.100lana.com, add an item, and check out. The store's merchant has **Verified buyers only** turned on.
2. On the hosted checkout, the **Quick human check** card comes first. Optionally select **Sign in with 0G** and paste a management key from [pc.0g.ai → API keys](https://pc.0g.ai/dashboard/api-keys) with the `account:read` and `keys:create` scopes. Your 0G balance appears.
3. Select **Start human check**. 0G Private Computer draws a fresh picture with `z-image-turbo` in a TEE.
4. Type what you see, or press the mic and say it (Whisper on 0G). `0gm-1.0` judges the answer.
5. Open **Paid by your 0G account · N 0G requests**. It lists each request ID and your balance before and after the check.
6. The **Verified buyer** badge appears and the pay button unlocks. Signed-in buyers keep the badge for 30 days on every Whitechain store, so the next checkout skips the picture.
7. Merchant side: in the dashboard, **Payments** shows the badge, and the payment page lists the 0G request IDs. **Settings → Verified buyers** shows the check stats. The check is switched on per checkout in code with `requireVerifiedBuyer: true` and `verifiedBuyerMethod: "zg"`.

## Where 0G is in the code

- `apps/dashboard/src/lib/zg/router.ts`: 0G router client (images, chat, transcription, balance, key minting). It records `X-Request-ID` on every call.
- `apps/dashboard/src/lib/zg/human-check.ts`: challenge → answer → judge, rate limits, request-ID log.
- `apps/dashboard/src/lib/zg/buyers.ts`: Sign in with 0G, the capped daily key on the buyer's account, and encrypted key storage.
- `apps/dashboard/src/app/checkout/[sessionId]/human-check.tsx`: the checkout UI.
